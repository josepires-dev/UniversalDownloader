# Runtime tools

The executable tools are intentionally not committed to this repository because they are large third-party distributions.

Place the following files directly in this directory for a Windows/XAMPP installation:

| File | Purpose | Official source |
|---|---|---|
| `yt-dlp.exe` | Extract metadata and download media | [yt-dlp releases](https://github.com/yt-dlp/yt-dlp/releases) |
| `ffmpeg.exe` | Merge media streams and convert audio to MP3 | [FFmpeg downloads](https://ffmpeg.org/download.html) |
| `gallery-dl.exe` | Download supported Instagram galleries | [gallery-dl releases](https://github.com/mikf/gallery-dl/releases) |

Do not download executables from unofficial mirrors. Keep this folder protected from direct web access through the included `.htaccess` file.
